# pii-go — Go-порт горячего ядра PII Security Proxy

Экспериментальная ветка `feature/go-rewrite`: производительное ядро сервиса на Go
(stdlib `net/http`, один процесс, все ядра без GIL).

## Что портировано 1:1

- Контракт `POST /process` (`{payload, payload_id} → {result}`), направление по
  HMAC-SHA-256 fingerprint'ам, идемпотентные ретраи, exact-сплайс по
  пооккуренсным span'ам, fuzzy-демаск LLM-изменённого текста (token + synthetic,
  word-bounded), grace-lifecycle.
- Все структурные детекторы: email, phone (RU+intl), ИНН (контрольные цифры),
  карта (Luhn), паспорт (4 формы), код подразделения, CVV/PIN (keyword-gated),
  ВУ, даты с классификацией роли, адрес, место рождения, гражданство, орган
  выдачи, cardholder. Граница «не-цифра» вместо lookaround (RE2).
- Контекстный движок: word-start keyword-матчинг с хвостом ≤2 симв.,
  private/public скоринг, org/personal адреса, правило «PIN только рядом с
  картой» с границей абзаца.
- Режимы partial/token/synthetic; синтетика детерминирована от
  `(payload_id, identity)`, ИНН/карты проходят контрольные суммы.
- Mongo (авторитет) + Redis (кэш) + breakers, fail-fast таймауты, fail-closed
  семантика, no-PII degraded-путь, 413/429 + Retry-After, Prometheus-метрики.

## Осознанные отличия от Python-версии

- **Морфология**: pymorphy3-аналога в Go нет. ФИО детектируются суффиксными
  эвристиками + словарём имён; нормализация идентичности эвристическая.
  Synthetic-имена генерируются только в именительном падеже; склонённые
  упоминания получают TOKEN-fallback (та же политика, что у Python при низкой
  уверенности морфологии). Partial (инициалы) и token — полноценные.
- Entity resolution упрощён до нормализованных ключей (без alias-merge
  инициальных форм с полными).
- ML-фолбэк не портирован (в референсе выключен по умолчанию).

Итого: **контракт и нагрузочное поведение — паритет; лингвистическое качество
(склонение синтетики, alias-resolution) — ниже референса.** Go-ветка отвечает
на вопрос «сколько RPS стоит Python», а не заменяет прод.

## Сборка и запуск

```bash
docker build -t pii-go go-service/
docker run --rm -p 8090:8090 \
  -e PII_MONGO_URL=mongodb://mongo:27017 -e PII_REDIS_URL=redis://redis:6379/0 \
  pii-go
```

Тесты выполняются этапом docker-сборки (`go vet && go test`). Локально:
`go test ./pii/`.

отличия» выше — лингвистическое качество ниже референса.
